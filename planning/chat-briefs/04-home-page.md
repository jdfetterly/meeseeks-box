# Chat Brief: Home Page

You are helping define the Home page for Meeseek Box.

## Product Direction

Home should be a briefing and dispatch surface, not a monitoring dashboard.

It should help the user decide:

- what needs attention
- what outputs are ready for review
- which active projects matter most
- what the next delegation should be

## Locked Decisions

- Chat is the control plane.
- Review Queue is separate from Inbox.
- Projects are first-class.
- Home is the front door, but detailed work happens in Projects, Board, Review, and Chat.
- Workspace-ready vs planning-only project state matters.

## What This Chat Should Produce

Define the Home page:

- primary sections
- prioritization rules
- what objects appear there
- what actions should be available directly from Home
- how the user moves from Home into action

## Please Cover

- `Needs Your Attention`
- `Review Ready`
- `Active Projects`
- `Recent Agent Progress`
- `Quick Delegate`

Also define:

- what should never appear on Home
- how much detail each section should show
- mobile vs desktop behavior if relevant

## Constraints

- Home should not feel like a raw status dashboard.
- It should support decision-making and delegation.
- It should reflect project context, not only operational state.

## Output Format

Return:

1. Home page goals
2. Section-by-section spec
3. Prioritization logic
4. Actions and entry points
5. Acceptance criteria
